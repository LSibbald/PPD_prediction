This repository contains the code accompanying the paper:

> **Identifying prenatal risk factors of postpartum depression with machine learning**
> *Sibbald, L., van den Heuvel, M.I., Haas, M.R. et al. Identifying prenatal risk factors of postpartum depression with machine learning. Sci Rep 15, 34610 (2025). https://doi.org/10.1038/s41598-025-18204-6*

The code implements data preprocessing, model training, evaluation, and analysis pipelines used to identify prenatal risk factors associated with postpartum depression using machine-learning methods.

---

## Repository contents

The repository includes:

* Source code for data processing and feature engineering
* Machine-learning model training and evaluation scripts
* Analysis code used for the results reported in the paper

Due to privacy and information-security considerations, **no raw data, intermediate data artifacts, or trained model files are included** in this repository.

---

## Data availability

Sensitive data, intermediate results (e.g. serialized model files), and certain generated outputs are **intentionally excluded** from version control.
These include, but are not limited to:

* Serialized model files (`*.pkl`)
* Derived datasets and plots
* Files containing potentially sensitive or identifying information

This ensures compliance with data protection and information security requirements.
